## Leur catalogue (la mécanique)

1. **Produit héros** : Écran CarPlay 7" sans fil — « moins de 80 € » (≈ 79,95 €). C'est lui qui porte toute la pub.
2. **Gamme dongles** (pour les voitures qui ont déjà CarPlay filaire) : 39,95 € / 59,95 € / 69,95 € — monte le panier moyen.
3. **Accessoires** : supports téléphone compatibles MagSafe 19,95 €.
4. **Consommables à réachat** : parfum voiture 29,95 € + **recharges 19,95 €**, aspirateur 49,95 € + **filtres HEPA 9,95 €**. → revenus récurrents (leurs bestsellers actuels sont les recharges !).

**La leçon** : le héros fait l'acquisition, les consommables font la LTV. CleanTech a DÉJÀ les consommables (produits detailing) — il manque juste le héros. C'est exactement le bon fit.

## Leurs angles de pubs (ce qui tourne depuis des semaines)

1. **La peur de l'amende** (leur pub principale, storytelling long) : « Tu le fais. Tout le monde le fait. Juste regarder quel message arrive… 440 € d'amende. Deux fois et ton permis est sur la table. » → le produit lit les messages via Siri/Google Assistant, mains sur le volant. *En France : 135 € + 3 points → angle encore plus fort avec le retrait de permis.*
2. **La rage du support téléphone** (storytelling long) : « Ton support téléphone est nul. Un téléphone sur une pince en plastique collée au pare-brise. En 2025. Tu payes des milliers d'euros pour une voiture et tu navigues avec un truc qui tombe à chaque dos-d'âne. » → écran fixe, monté, qui ne bouge pas.
3. **La honte de la vieille voiture** : « Arrête de naviguer comme en 2010 » / « CarPlay dans CHAQUE voiture ! » → moderniser sans passer par le garage (pas d'installation chère).
4. **Version liste ✔️ courte** (retargeting) : 7" tactile ✔️ sans fil ✔️ connexion auto ✔️ toute voiture ✔️ + réassurance livraison/retour/garantie + « moins de 80 € » + urgence stock.

**Style** : texte long, phrases très courtes, deuxième personne, zéro emoji dans les storytelling (emojis seulement dans la version liste), toujours la même fin : prix + « demain chez toi » + « 3 minutes d'installation » + urgence douce (OP = OP → « stock limité »).

## Pourquoi c'est jouable pour CleanTech en France

- Personne ne domine cet angle en FR comme CarMe le fait en NL (à re-vérifier via product-scout avant lancement).
- CleanTech a déjà : la marque auto, le site Shopify, le cycle email Klaviyo, les produits detailing en cross-sell.
- L'écran attire un trafic large (tous les conducteurs) → le detailing se vend derrière en post-achat.
